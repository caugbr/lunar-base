Introdução

Utilize a classe AdminMenu no método boot() do ServiceProvider do seu plugin para injetar novos itens ou criar seções inteiras com títulos no menu lateral do Lunar Base. O menu é renderizado automaticamente na barra lateral, respeitando permissões, roles e agrupamentos.

Criando Novas Seções (Grupos)

Se o seu plugin precisar criar um grupo de navegação dedicado na sidebar com seu próprio título (ex: Ensino, E-commerce, Ferramentas), utilize o método AdminMenu::addSection():

PHPuse App\Support\AdminMenu;

// Cria a seção "Ensino" no topo do menu (posição/índice 0)
AdminMenu::addSection('Ensino', [], 0);

A assinatura do método addSection() aceita três parâmetros:

  • $title (string, obrigatório): Título visível do cabeçalho da seção na sidebar.
  • $items (array, opcional): Array inicial de itens para pré-popular a seção.
  • $index (int|null, opcional): Posição numérica da seção na sidebar (0 para o topo, 1 para segunda posição, ou null para inserir ao final).
Idempotência: Se dois plugins tentarem criar uma seção com o mesmo título (ex: "Ensino"), o sistema une os itens na mesma seção sem duplicar o cabeçalho no menu.

Sintaxe do AdminMenu::add()

Para injetar um item de primeiro nível em uma seção específica, utilize o método AdminMenu::add():

PHPuse App\Support\AdminMenu;

AdminMenu::add([
    'label'      => 'Cursos',
    'icon'       => 'book-open',        // Ícone Lucide
    'route'      => 'admin.courses.index',
    'active'     => 'admin.courses.*',
    'permission' => 'view-courses',     // Permissão (opcional)
    'role'       => 'admin',            // Role (opcional)
], null, 0); // Param 2: após qual item? | Param 3: índice do grupo (0 por padrão)

Parâmetros

Campos do Array de Item

Campo Obrigatório Descrição
label Sim Texto exibido no link do menu.
icon Sim Nome do ícone Lucide (ex: 'book-open', 'settings', 'users').
route Sim Nome da rota Laravel cadastrada.
active Sim Padrão que define se o item está ativo (use * como wildcard, ex: admin.courses.*).
permission Não Exibe o item apenas para usuários com essa permissão do sistema RBAC.
role Não Exibe o item apenas para usuários com essa role (admin, editor, etc.).

Assinatura dos Métodos

Método Assinatura Descrição
addSection() addSection(string $title, array $items = [], ?int $index = null) Cria ou mescla um grupo/seção com título na sidebar.
add() add(array $item, ?string $afterLabel = null, int $groupIndex = 0) Injeta um item na seção indicada pelo $groupIndex.
addSubItem() addSubItem(string $parentLabel, array $subItem, ?string $afterLabel = null) Injeta um sub-item dentro do dropdown de um item pai.
Ícones Disponíveis: Consulte a biblioteca Lucide Icons para escolher o ícone desejado.

Exemplo Completo

No ServiceProvider do Plugin

PHPnamespace Plugins\Caminho;

use Illuminate\Support\ServiceProvider;
use App\Support\AdminMenu;

class CaminhoServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // 1. Cria a seção "Ensino" na primeira posição do menu (índice 0)
        AdminMenu::addSection('Ensino', [], 0);

        // 2. Injeta os itens dentro da seção de índice 0 ("Ensino")
        AdminMenu::add([
            'label'      => 'Cursos',
            'icon'       => 'book-open',
            'route'      => 'admin.courses.index',
            'active'     => 'admin.courses.*',
            'permission' => 'view-courses',
        ], null, 0);

        AdminMenu::add([
            'label'      => 'Turmas',
            'icon'       => 'calendar',
            'route'      => 'admin.classes.index',
            'active'     => 'admin.classes.*',
            'permission' => 'view-classes',
        ], null, 0);
    }
}

Posicionamento de Seções e Itens

1. Posicionamento de Seções (`addSection`)

As seções na sidebar obedecem ao parâmetro $index numérico:

  • 0: Posiciona a nova seção no topo do menu.
  • 1: Posiciona como o segundo grupo da sidebar.
  • null (padrão): Insere a seção ao final do menu.

2. Posicionamento de Itens dentro da Seção (`add`)

Dentro de cada seção, os itens utilizam o parâmetro $afterLabel para posicionamento relativo. O novo item será inserido imediatamente após o item com o rótulo especificado. Se for omitido ou null, o item vai para o final da sua seção.

Boas Práticas

  • Organize por Seções: Use AdminMenu::addSection() para agrupar módulos complexos e manter a sidebar limpa e intuitiva.
  • Use permissões: Sempre defina o campo permission para ocultar links de usuários não autorizados.
  • Ícones semânticos: Escolha ícones do Lucide que transmitam claramente a função do módulo.
  • Wildcard no active: Use admin.meumodulo.* no campo active para que o item permaneça destacado em telas de edição e cadastro.
