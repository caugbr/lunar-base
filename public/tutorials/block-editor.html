Introdução

O editor de conteúdo do Lunar Base é baseado em uma árvore de dados estruturados utilizando Tiptap (ProseMirror) e Vue 3. Diferente de editores tradicionais baseados em HTML bruto, o editor do Lunar Base trata cada elemento da página como um nó tipado e independente (parágrafos, cards, avisos, tabelas, colunas, imagens com legenda).

Plugins e temas podem injetar novas extensões em tempo de execução sem recompilar o núcleo do sistema, criando desde simples botões de formatação até componentes interativos complexos.

Árvore em JSON Limpa

Estrutura previsível de nós e atributos que pode ser consumida por APIs, aplicativos móveis ou exportadores.

Componentes Vue Nativos

Crie blocos visuais com botões de controle, estados reativos e seletores embutidos usando NodeViews.

Renderização Instantânea

O editor pré-compila HTML semântico ao salvar, garantindo que o front-end público não sofra atrasos de parsing.

O Modelo de Dados (JSON vs HTML)

O editor opera com um fluxo bidirecional de dados automatizado pelo componente <x-editor />:

Campo no Banco Tipo Finalidade
content_json JSON / LongText A árvore de nós do ProseMirror. É carregada exclusivamente no painel admin para reabrir e editar os blocos.
content LongText (HTML) O HTML semântico final pré-renderizado. É consumido diretamente pelas views públicas do tema ({!! $post->content !!}).

Anatomia de um Bloco Tiptap

Um bloco customizado é criado através do método Node.create() exposto pelo motor global. Toda extensão possui 4 seções fundamentais:

JAVASCRIPTconst { Node, mergeAttributes } = window.LunarEditor;

const MeuBlocoExtension = Node.create({
    name: 'meuBloco',      // Identificador único do nó na árvore JSON
    group: 'block',        // 'block' (bloco de linha inteira) ou 'inline' (dentro de texto)
    content: 'block+',     // O que pode ser colocado dentro dele ('block+', 'inline*', ou vazio para átomos)
    defining: true,        // Preserva a estrutura do bloco ao colar conteúdo
    draggable: true,       // Permite arrastar e soltar o bloco

    // Atributos persistidos no JSON do nó
    addAttributes() {
        return {
            tipo: { default: 'destaque' },
            autor: { default: '' }
        };
    },

    // Como o Tiptap reconhece este bloco ao abrir um HTML existente
    parseHTML() {
        return [{ tag: 'div[data-type="meu-bloco"]' }];
    },

    // Como este bloco é gravado no banco como HTML para o visitante
    renderHTML({ HTMLAttributes }) {
        return [
            'div',
            mergeAttributes(HTMLAttributes, { 'data-type': 'meu-bloco', class: 'lunar-meu-bloco' }),
            0 // O número 0 indica onde o conteúdo editável interno será renderizado
        ];
    },

    // (Opcional) Vincula o visual do nó a um componente reativo do Vue
    addNodeView() {
        return VueNodeViewRenderer(MeuBlocoComponent);
    }
});

Interfaces Reativas com Vue (NodeViews)

Se o seu bloco precisa de controles visuais durante a edição (como botões de exclusão, seletores de cor, abas ou inputs de configuração que não devem aparecer no site público), utilize uma NodeView:

Componentes Especiais da NodeView:
  • NodeViewWrapper: Container obrigatório que encapsula o nó no DOM do Vue.
  • NodeViewContent: Elemento que diz ao Tiptap onde o autor tem permissão para digitar texto dentro do bloco.
  • updateAttributes(): Função utilitária que altera os atributos do nó de forma reativa.

Exemplo de Componente Vue em JavaScript Puro:

JAVASCRIPTconst { NodeViewWrapper, NodeViewContent, Vue } = window.LunarEditor;
const { h } = Vue;

const CardComponent = {
    props: ['node', 'updateAttributes', 'deleteNode'],
    setup(props) {
        return () => h(NodeViewWrapper, { class: `card-box card-${props.node.attrs.tipo}` }, [
            // Barra de ferramentas administrativa (invisível no front-end)
            h('div', { class: 'card-admin-bar', contenteditable: 'false' }, [
                h('span', 'CARD PERSONALIZADO'),
                h('button', {
                    type: 'button',
                    onClick: () => props.updateAttributes({ tipo: 'sucesso' })
                }, 'Mudar para Verde'),
                h('button', {
                    type: 'button',
                    class: 'btn-delete',
                    onClick: () => props.deleteNode()
                }, '🗑️')
            ]),

            // Área livre onde o autor digita o texto
            h(NodeViewContent, { class: 'card-conteudo' })
        ]);
    }
};

Registrando no Editor (window.LunarEditor)

O objeto global window.LunarEditor é a ponte de entrada para registrar extensões fornecidas pelo seu plugin:

Método Parâmetros Descrição
registerBlock() blockConfig (Object) Registra o bloco e cria o botão correspondente no Mega-Menu "Inserir Bloco".
registerToolbarButton() buttonConfig (Object) Adiciona um botão de acesso rápido diretamente na barra superior da Toolbar.

Configuração de Registro de Bloco (registerBlock):

JAVASCRIPTwindow.LunarEditor.registerBlock({
    name: 'nomeDoNo',               // Nome declarado no Node.create()
    category: 'Estrutura & Layout', // Categoria no Mega-Menu
    title: 'Título do Botão',       // Título exibido no menu
    description: 'Breve resumo',    // Descrição auxiliar do recurso
    extension: MinhaExtensaoNode,   // A classe de extensão criada
    action: (editor) => {           // Ação executada ao clicar no botão
        editor.chain().focus().insertContent({
            type: 'nomeDoNo',
            attrs: { /* atributos iniciais */ },
            content: [{ type: 'paragraph', content: [{ type: 'text', text: 'Texto inicial...' }] }]
        }).run();
    }
});

Posicionamento de Ações na Interface

O Lunar Base permite que o plugin decida onde seus botões devem aparecer na tela de edição:

1. Inserir em Coluna Nativa Existente

Use category: 'Estrutura & Layout' ou category: 'Mídia & Conteúdo' para agrupar o botão junto aos blocos padrão do sistema.

2. Criar Nova Coluna Temática

Definir qualquer outro nome em category (ex: 'E-commerce', 'Formulários') cria uma nova coluna temática no Mega-Menu automaticamente.

3. Botão Direto na Barra Superior

Para ferramentas globais de texto ou utilitários rápidos, utilize registerToolbarButton():

JAVASCRIPTwindow.LunarEditor.registerToolbarButton({
    name: 'meu_utilitario',
    title: 'Traduzir Texto',
    icon: '🌐', // Texto, emoji ou caractere
    action: (editor) => {
        // Executa comandos no editor ativo
        const textoSelecionado = editor.state.doc.textBetween(
            editor.state.selection.from,
            editor.state.selection.to
        );
        alert(`Texto selecionado: ${textoSelecionado}`);
    }
});

Exemplo Prático Completo

Este exemplo demonstra a criação de um plugin completo que adiciona um bloco de Caixa de Destaque com Autor.

1. Service Provider do Plugin (MeuPluginServiceProvider.php):

PHPnamespace Plugins\MeuDestaque;

use Illuminate\Support\ServiceProvider;
use App\Services\EditorManager;

class MeuDestaqueServiceProvider extends ServiceProvider
{
    public function boot(): void
    {
        // Injeta o script do editor no painel admin
        EditorManager::registerScript(asset('plugins/meu-destaque/js/destaque-block.js'));

        // Injeta o CSS correspondente no painel admin
        EditorManager::registerStyle(asset('plugins/meu-destaque/css/editor.css'));

        // Enfileira o CSS para exibição correta no site público
        add_style('meu-destaque-front', asset('plugins/meu-destaque/css/front.css'), [], '1.0.0');
    }
}

2. Script do Bloco (public/plugins/meu-destaque/js/destaque-block.js):

JAVASCRIPT(function() {
    'use strict';

    if (!window.LunarEditor) return;

    const { Node, mergeAttributes, VueNodeViewRenderer, NodeViewWrapper, NodeViewContent, Vue } = window.LunarEditor;
    const { h } = Vue;

    // Componente Vue da NodeView
    const DestaqueComponent = {
        props: ['node', 'updateAttributes'],
        setup(props) {
            return () => h(NodeViewWrapper, { class: 'plugin-destaque-box' }, [
                h('div', { class: 'plugin-destaque-bar', contenteditable: 'false' }, [
                    h('span', '⭐ DESTAQUE ESPECIAL'),
                    h('button', {
                        type: 'button',
                        onClick: () => {
                            const autor = prompt('Autor da frase:', props.node.attrs.autor);
                            if (autor !== null) props.updateAttributes({ autor });
                        }
                    }, 'Definir Autor')
                ]),
                // Área onde o autor escreve o texto livre
                h(NodeViewContent, { class: 'plugin-destaque-texto' }),
                h('footer', { class: 'plugin-destaque-footer', contenteditable: 'false' }, `— ${props.node.attrs.autor || 'Anônimo'}`)
            ]);
        }
    };

    // Extensão do Nó Tiptap
    const DestaqueExtension = Node.create({
        name: 'caixaDestaque',
        group: 'block',
        content: 'block+',
        defining: true,

        addAttributes() {
            return {
                autor: { default: '' }
            };
        },

        parseHTML() {
            return [{ tag: 'div[data-type="caixa-destaque"]' }];
        },

        renderHTML({ HTMLAttributes }) {
            return [
                'div',
                mergeAttributes(HTMLAttributes, {
                    class: 'lunar-caixa-destaque',
                    'data-type': 'caixa-destaque'
                }),
                ['div', { class: 'lunar-destaque-conteudo' }, 0],
                HTMLAttributes.autor ? ['footer', { class: 'lunar-destaque-autor' }, `— ${HTMLAttributes.autor}`] : ''
            ];
        },

        addNodeView() {
            return VueNodeViewRenderer(DestaqueComponent);
        }
    });

    // Registro no Menu de Blocos
    window.LunarEditor.registerBlock({
        name: 'caixaDestaque',
        category: 'Estrutura & Layout',
        title: 'Caixa de Destaque',
        description: 'Citação destacada com identificação de autor',
        extension: DestaqueExtension,
        action: (editor) => {
            editor.chain().focus().insertContent({
                type: 'caixaDestaque',
                attrs: { autor: 'Nome do Autor' },
                content: [{ type: 'paragraph', content: [{ type: 'text', text: 'Escreva a frase de destaque...' }] }]
            }).run();
        }
    });
})();

Boas Práticas de Desenvolvimento

⚠️ Isolamento de CSS Obrigatório:

Nunca aplique estilos genéricos soltos (ex: p { ... } ou button { ... }). Todas as regras de estilo de um plugin devem começar obrigatoriamente com a classe container do seu próprio bloco para não quebrar outros elementos do painel ou dos temas:

CSS/* Correto: totalmente encapsulado pelo prefixo do plugin */
.plugin-destaque-box {
    background: #f8fafc;
    border-left: 4px solid #3b82f6;
    padding: 16px;
    border-radius: 6px;
}

.plugin-destaque-box button {
    background: #e2e8f0;
    font-size: 11px;
}
  • Utilize contenteditable="false" em Elementos de Interface: Todo botão, cabeçalho de card, selo ou controle administrativo dentro da sua NodeView deve possuir o atributo contenteditable="false". Isso impede que a digitação do autor invada os botões.
  • Evite Tags HTML Fantasmas: No método renderHTML(), só gere tags secundárias (como <footer> ou <figcaption>) se os atributos correspondentes realmente possuírem valor preenchido.
  • Transações Atômicas: Ao manipular a árvore de nós via comandos personalizados, agrupe as alterações em uma única transação do ProseMirror (state.tr) para manter a pilha de Desfazer/Refazer (Undo/Redo) consistente.
