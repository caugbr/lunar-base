Introdução

A partir da versão v1.2.0, o Lunar Base adota uma arquitetura totalmente desacoplada para extensões. Os plugins oficiais e temas não ficam mais embutidos no núcleo do sistema, mas sim mantidos em um repositório centralizado dedicado em https://github.com/caugbr/lunar-base-addons.

Através do Marketplace de Plugins (acessível no painel em Admin → Plugins → Instalar plugin), você pode explorar, baixar, ativar, desativar ou remover qualquer módulo de forma dinâmica com apenas um clique.

Marketplace Integrado

Baixe e descompacte plugins oficiais do repositório remoto diretamente no painel administrativo.

Núcleo Leve

O core do sistema permanece enxuto. Você instala apenas os módulos que realmente utilizar no seu projeto.

Hooks e Shortcodes

Módulos ativados se conectam dinamicamente ao tema via hooks e expõem shortcodes no editor de texto.

1. Avatars (Imagens de Perfil)

Permite que usuários façam upload de fotos de perfil personalizadas. A imagem é automaticamente recortada em 150×150px, convertida para WebP e exibida em todo o site.

Como funciona

  • Upload de imagens de até 5MB
  • Recorte automático em formato quadrado
  • Conversão para WebP (qualidade 90)
  • Fallback automático para Gravatar se não houver foto
  • Exclusão automática ao remover o usuário

Onde aparece

Local Comportamento
Header do admin Miniatura circular do usuário logado
Página de Perfil Card com upload e preview
Comentários Avatar do autor (se Comments ativo)

Como usar no tema

Exibindo avatar

<img src="{{ \Plugins\Avatars\Helpers\AvatarHelper::getUrl($user) }}"
     alt="Avatar"
     class="avatar-circle-sm">
Dica: o helper aceita tanto um objeto User quanto uma string de e-mail (útil para visitantes).

Hooks utilizados

  • admin.header_user_avatar - Header do painel
  • admin.profile_after_card - Página de perfil

2. Backup (Gerenciador de Backups)

Módulo completo para geração, download, importação externa e restauração em 1 clique de cópias de segurança do site.

Como funciona

  • Pacotes Modulares em .ZIP: Escolha entre incluir Banco de Dados (SQL/SQLite), Mídias (`storage/app/public`), Plugins e Temas.
  • Importação de ZIPs Externos: Faça upload de arquivos `.zip` gerados em outras máquinas para restaurar ou migrar sites facilmente.
  • Restauração em 1 Clique: Substitui dados e arquivos com trava de segurança visual e bloqueio contra fechamento do navegador.
  • Comando CLI para Automação: Permite agendar tarefas automáticas no servidor (Cron) via Artisan.

Como usar no Painel

1Acesse Admin → Sistema → Backups

2Clique em "Criar Backup"

Selecione as partes que deseja incluir e clique em "Iniciar Backup".

3Importe ou Restaure

Use o botão "Importar Backup" para enviar um `.zip` do computador ou clique em "Restaurar" em qualquer item da tabela.

Comando Artisan para Servidor (Cron Job)

Executando backup via linha de comando

php artisan backup:run
Clonagem de Site: O arquivo `.zip` gerado contém o banco, mídias, temas e plugins. Você pode instalar o Lunar Base limpo em um servidor novo e usar o "Importar Backup" para ter uma cópia 100% idêntica rodando em segundos.

3. Banners (Gerenciador de Publicidade)

Gerencie campanhas internas ou externas de publicidade visual com suporte a múltiplos métodos de exibição e controle analítico de cliques.

Como funciona

  • Exibição flexível (Shortcodes, Hooks dinâmicos ou Helper Global).
  • Rastreamento detalhado de cliques salvando Timestamp, endereço de IP e User Agent.
  • Redirecionamento HTTP 301 intermediário para contabilização segura.
  • Painel analítico integrado com gráficos diários e históricos recentes de cliques.

Métodos de Exibição

1. Shortcode (Conteúdo de Posts/Páginas)

[banner slug="promocao-verao"]
[banner slug="banner-lateral" class="rounded-lg shadow-lg"]
Nota: A propriedade class opcional sobrescreve a classe padrão definida no painel.

2. Helper PHP (Arquivos do Tema)

{!! renderBanner('promocao-verao') !!}
{!! renderBanner('promocao-verao', 'custom-class-here') !!}

3. Injeção Automática via Hook

Selecione um ponto de exibição (Hook) cadastrado no tema durante o cadastro do banner. Ele será injetado de forma dinâmica sem necessidade de alteração de código.

Otimização: Sempre dê preferência por imagens no formato WebP ou JPG otimizados no gerenciador de mídia para não prejudicar o carregamento do tema.

4. Comments (Comentários nos posts)

Sistema completo de comentários com respostas aninhadas, moderação de spam e integração com avatares.

Como funciona

  • Aparece automaticamente ao final de cada post
  • Visitantes comentam com nome e e-mail; usuários logados com um clique
  • Respostas aninhadas ilimitadas
  • Moderação automática de palavras suspeitas

Como usar

Não precisa fazer nada! O plugin se conecta automaticamente ao hook post.footer_end.

Moderação

Comentários com estas palavras vão para moderação:

buy, viagra, free casino, spam, cryptocurrency, click here

Hook utilizado

post.footer_end

3Adicione perguntas

7. Galleries (Galerias de Imagens)

Exiba galerias de imagens vinculadas aos seus posts ou páginas de forma responsiva utilizando o shortcode nativo [gallery].

Como funciona

O plugin identifica automaticamente as mídias vinculadas ao post ou página atual (via relação polimórfica com a tabela de mídias). Ele carrega de forma otimizada os estilos CSS e comportamentos JS somente sob demanda, quando a galeria é renderizada em tela.

  • Três formatos de visualização: Grid de colunas estático, carrossel dinâmico (com suporte a setas e navegação por teclado) e Masonry (ajuste de proporções variadas, estilo Pinterest).
  • Lightbox integrado: Visualizador de tela cheia programado em vanilla JS, permitindo avançar, retroceder e fechar com atalhos de teclado (setas e Esc) e navegação simplificada.
  • Gestão de dimensões: Escolha entre diferentes resoluções de imagens dependendo de sua necessidade estética e de desempenho.
  • Parâmetros visuais: Definição inline de espaçamentos, cantos arredondados, legendas e proporções de tela.

Atributos do Shortcode

Atributo Valores Aceitos Padrão Descrição
layout grid, masonry, carousel grid Formato de estruturação das imagens.
ids Lista de IDs numéricos separados por vírgula — Renderiza imagens específicas diretamente do banco de dados (ignora o vínculo com o post atual).
columns / cols 1 a 6 3 Quantidade de colunas de imagens exibidas paralelamente (para layouts grid e masonry).
size thumb, medium, large, original medium Resolução das imagens exibidas (Thumb: miniatura 300x300px; Medium: versão redimensionada de 800px).
limit Número inteiro positivo — Restringe a quantidade máxima de itens carregados na galeria.
orderby id, name, created_at created_at Critério para ordenação das mídias.
order asc, desc, rand asc Sentido de exibição da galeria. Utilize rand para carregar imagens aleatórias a cada visita.
lightbox true, false true Ativa ou desativa a ampliação e visualização de fotos em modal ampliado.
caption true, false true Mostra legendas e títulos cadastrados sobre as imagens durante eventos de hover.
gap Número inteiro (pixels) 8 Espaçamento interno de distância entre os cartões de imagem.
ratio square, 4/3, 16/9, auto square Configura o aspect-ratio fixo para as imagens no layout grid.
rounded true, false true Aplica raios de borda arredondada (border-radius de 8px) nas mídias.
exclude_thumbnail true, false true Se definido como true, impede a duplicação da imagem principal de destaque do post dentro do corpo da galeria.

Exemplos de Configuração

Grid Padrão de 3 Colunas

[gallery]

Galeria de Alturas Variadas (Pinterest style)

[gallery layout="masonry" columns="3" gap="12"]

Carrossel de Slides com Imagens Médias

[gallery layout="carousel" size="medium"]

Galeria com Seleção Manual de IDs e Proporção Cinema

[gallery ids="4,12,18,31" ratio="16/9" rounded="false"]
Recomendação de Performance: Dê preferência ao tamanho size="medium" na maioria das galerias. Ele entrega boa visualização em telas de computadores e smartphones, sem comprometer a transferência de banda e performance de carregamento da página.

8. Maintenance (Modo de Manutenção)

Bloqueia o acesso público ao site exibindo uma página de "em manutenção".

Como ativar

1Admin → Configurações → Manutenção

2Marque "Ativar modo de manutenção"

3Personalize a página

Ícone, título, mensagem, footer

Quem acessa durante manutenção

  • Admin e editores: navegam normalmente
  • Rotas /admin, /login: continuam funcionando
  • Visitantes: veem apenas a página de manutenção
SEO: retorna status HTTP 503 - o Google não indexa a página de manutenção.

11. Populator (Gerador de Conteúdo de Teste)

Gera massa de dados fictícios de forma rápida para popular o site durante as etapas de desenvolvimento ou demonstração.

Como funciona

  • Usuários: Cria contas com nomes realistas brasileiros, atribuições de papéis (roles) randômicas e gera uma senha temporária exibida em tela.
  • Posts e Páginas: Cria registros contendo títulos, resumos e parágrafos estruturados de Lorem Ipsum em português, mesclando listas e subtítulos.
  • Tratamento de Imagens: Baixa e registra imagens de destaque (thumbnails) ou arquivos de galeria localmente via Picsum, e injeta tags <figure> com links externos no HTML do conteúdo.

Como usar

1Acesse Admin → Configurações → Populator

2Gerar Usuários primeiro

Sempre crie usuários antes dos posts/páginas, pois as publicações exigem a vinculação de um autor existente.

3Configurar quantidade e mídia

Escolha o número de itens, status (Publicado/Rascunho) e quantidade máxima de imagens internas ou de galeria.

Aviso: A geração de posts/páginas com thumbnails ou imagens de galeria realiza requisições externas para baixar os arquivos de teste, o que pode demorar alguns segundos conforme sua conexão.

12. PrismHighlight (Syntax Highlighting)

Exiba blocos de código formatados com destaque de sintaxe profissional usando Prism.js diretamente nos seus posts e páginas.

Como funciona

O plugin intercepta o shortcode [code] e o renderiza em um bloco vetorial estético, completo com barras de janela simulando macOS (bolinhas vermelha, amarela e verde) ou formato Plain limpo, suportando múltiplos temas visuais.

Atributos do Shortcode `[code]`

Atributo Valores Aceitos Padrão Descrição
lang php, javascript, vue, markup, css, scss, bash, sql, json php A linguagem de programação para aplicar a coloração de sintaxe correta.
title Qualquer texto (ex: app.php) — Exibe o nome do arquivo no cabeçalho da janela do bloco de código.
style mac, plain mac Estilo visual do contêiner (com botões de janela macOS ou formato minimalista).
theme tomorrow, okaidia, dracula, one-dark, solarizedlight, default tomorrow Esquema de cores e tema visual do Prism.js.

Exemplos de Uso

Bloco em PHP com Estilo Mac

[code lang="php" title="app.php" style="mac" theme="tomorrow"]
<?php
class WebMaker {
    public function manifesto() {
        return 'Desenvolvimento é arte, não corrida.';
    }
}
[/code]

Snippet de JavaScript em Tema Claro

[code lang="javascript" title="main.js" theme="solarizedlight"]
console.log('Lunar Base v1.3.0 - Sem inchaço, sem complicações.');
[/code]
Otimização de Carregamento: O plugin carrega os recursos do Prism.js de forma assíncrona (via CDN) apenas quando identifica que a página renderizada possui um bloco de código `[code]`.

13. QrCode (Gerador de QR Code)

Gere imagens vetoriais (SVG) de QR Code para URLs, textos avulsos ou links diretos de artigos para fácil compartilhamento e impressão.

Como funciona

  • Gerador Avulso no Painel: Ferramenta dedicada em Admin → Ferramentas → Gerador QR Code para criar códigos vetoriais personalizados com preview ao vivo e download em SVG de alta resolução.
  • Integração com Posts e Páginas: Modais de visualização rápida acessíveis pelas tabelas de listagem e pelo cabeçalho do formulário de edição de publicações.
  • Desempenho Vetorial: Utiliza o motor vetorial nativo em SVG (`BaconQrCode`), garantindo imagens nítidas em qualquer dimensão e zero acúmulo de arquivos estáticos temporários no banco ou disco.

Onde aparece no Painel

Local Recurso / Comportamento
Ferramentas → Gerador QR Code Gerador livre de texto, URL, PIX ou chaves com seletor de resolução e download em SVG
Tabela de Posts e Páginas Ícone de ação rápida com botão de QR Code para abrir o modal com link público
Header de Edição de Posts e Páginas Botão "QR Code" destacado no topo ao lado das ações do artigo

Como usar no Tema ou Código PHP

Gerando SVG via Helper do Plugin

{!! \Plugins\QrCode\Helpers\QrCodeHelper::svg('https://seusite.com/post-1', 200) !!}

Hooks utilizados

  • admin.post_actions - Coluna de ações na tabela de Posts
  • admin.page_actions - Coluna de ações na tabela de Páginas
  • admin.edit_post_header_buttons - Topo da tela de edição de Posts
  • admin.edit_page_header_buttons - Topo da tela de edição de Páginas

14. Reactions (Curtidas e Engajamento)

Adiciona botões de reação (curtir/não curtir) ao final dos posts.

Como funciona

  • Aparece automaticamente via hook post.meta_end
  • Visitantes reagem sem login
  • Contadores atualizados via AJAX
  • 1 voto por IP (evita spam)

Configurações

Admin → Configurações → Leitura → Reactions:

  • Ativar/desativar reações
  • Tipo: 👍 Legal, ❤️ Coração, ⭐ Estrela
  • Permitir reação negativa
  • Reação única por visitante

Hook utilizado

post.meta_end
